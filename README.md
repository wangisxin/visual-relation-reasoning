# 图像关系推理系统

基于 YOLOv8 的多维图像识别与理解桌面应用。

## 功能

- 物体检测：识别图片中的 80 类常见物体
- 空间关系推理：判断物体之间的上下、左右、遮挡、前后关系
- 语义关系推理：理解物体之间的语义关联（人拿着、坐在、使用等）
- 物体计数：统计各类别物体数量

## 安装

```bash
pip install -r requirements.txt
```

首次运行时会自动下载 YOLOv8n 模型。

## 运行

```bash
cd src
python main.py
```

## 使用方法

1. 点击"上传图片"按钮选择一张图片
2. 系统自动进行物体检测和关系推理
3. 左侧显示标注后的图片，右侧显示分析结果
4. 可点击"保存结果图片"保存标注图
