# 图像关系推理系统 - 实现计划

## Success Criteria

1. 用户上传单张图片，系统输出：
   - 标注后的图片（显示物体框、类别、置信度）
   - 文字分析结果（空间关系、语义关系、计数）
2. 支持常见物体类别（COCO 80 类）
3. 纯本地运行，无需联网
4. 桌面应用形式（Windows exe）

## Risk Assessment

| 风险 | 严重度 | 缓解措施 |
|------|--------|----------|
| 关系推理准确率低 | 中 | 用规则 + 轻量模型组合 |
| 模型太大/难部署 | 中 | 用 YOLOv8n (nano) 最轻量版 |
| 桌面应用打包困难 | 低 | 用 PyQt/Tkinter 成熟方案 |

## 技术方案

### 架构

```
输入图片
    ↓
[YOLOv8n] 物体检测 → 获取 bbox, class, confidence
    ↓
[关系推理层]
  - 空间关系: 基于 bbox 坐标计算 (上下左右前后/遮挡)
  - 语义关系: 基于类别组合 + 位置特征
  - 计数: 统计各类别数量
    ↓
[桌面UI] 显示标注图 + 文字结果
```

### 依赖

- Python 3.8+
- ultralytics (YOLOv8)
- OpenCV (图像处理)
- PyQt6 / tkinter (桌面UI)

### 物体检测

- 模型: YOLOv8n (nano, ~6MB,最快)
- 类别: COCO 80 类

### 关系推理规则

**空间关系：**
- 上下: 比较 y 坐标中心
- 左右: 比较 x 坐标中心  
- 遮挡: IoU > 0.5 且一个框包含另一个
- 前后: 面积小 = 前，面积大 = 后

**语义关系：**
- 人-物: "人拿着/扶着/穿着/看着 X"
- 动物-物: "X 正在吃/玩/靠近 Y"
- 基于类别组合规则库

## 实施步骤

1. 环境搭建 + YOLO 推理测试
2. 物体检测模块 (获取 bbox, class)
3. 空间关系推理模块
4. 语义关系推理模块
5. 计数功能
6. 桌面 UI (图片上传 + 显示结果)
7. 打包 Windows exe

## Test Strategy

- 准备 5-10 张测试图片（不同场景）
- 验证物体检测召回
- 验证空间关系准确性
- 验证语义关系合理性
- UI 功能测试（上传、显示、保存）

## 预期输出

- 标注图: bbox 框出物体，标签显示类别+置信度
- 文字:
  - 检测到的物体列表
  - 空间关系 (N组)
  - 语义关系 (N组)
  - 计数结果
