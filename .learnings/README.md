# 学习记录

## 项目启动流程

本次项目采用新的 auto-project-flow 技能：

1. 需求访谈 - 通过多轮问答明确需求
2. 意图锁定 - 确认后再动手
3. 实施代码 - 按计划实现
4. 简化强化 - 代码自审
5. 学习捕获 - 记录经验

### 访谈技巧

- 分批次提问（2-3个/批），避免信息过载
- 先让用户确认方向，再细化技术细节
- 当用户说"你定"时，主动给出选项

### Baseline 选择

对于图像类项目：
- 经典方案：GitHub 搜索相关论文代码
- 现代方案：使用成熟模型 + 自建逻辑层
- 推荐组合：YOLO(检测) + 规则(关系)

### 技术要点

- YOLOv8n 是最小的模型，适合桌面应用
- 关系推理先用规则，验证有效后再考虑模型
- 桌面 UI 用 PyQt6，成熟稳定
